## 实现范围

- 独立 packages/local-mcp 包，stdio 启动，完整注册现有 28 个工具；不启动 HTTP 服务。
- SQLite 持久层与 D1 形状适配，复用原有迁移；有迁移校验、事务、外键、忙等待与原子条件写入。
- 自己的 Key 从 MCP 客户端环境读取，自己的数据目录存储；缺 Key 的账单请求失败关闭。
- 本地模式不冒称 Sites 身份；status 提供 adapter_version，保留核心 version 和工具 ID。
- 数据目录 0700、数据库 0600，拒绝明显不安全的符号链接/硬链接，拒绝根目录或家目录本身；错误不输出配置值。Windows ACL 行为本次未测试。
- 私人数据、依赖目录和构建目录的源码打包排除规则已更新。
