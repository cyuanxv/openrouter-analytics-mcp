# 0.5.0 功能与边界

| 能力 | 已提供 | 不包含 |
|---|---|---|
| 费用查询 | 余额、趋势、模型/供应商/Key 等维度 | 最终账单认证 |
| 调用记录 | 请求和 generation 元信息 | 聊天正文、业务会话自动映射 |
| 异常分析 | 本地日统计、稀疏小时对账、模型贡献 | 缺失当零、完整业务因果解释 |
| 报告 | 已完成周期报告、保存记录、发送认领和回执 | 自带定时器或 Telegram Bot |
| 模型比较 | 实时目录、价格和供应商信息 | 质量承诺、可用性承诺 |
| 成本实验 | 样本计划、人工评分、成本/延迟比较 | 自动付费推理 |
| 模型方案 | 版本、备用顺序、校验与导出 | 改动生产模型或创建 OpenRouter 原生预设 |

28 个 MCP 工具。保存报告、实验结果、模型预设、发送认领及回执会修改本地服务数据库；不能把所有工具统称为只读。

云端周报与提醒属于外部任务配置。报告 `should_notify=false` 时不发送；发前认领，得到真实回执才记录成功；未知结果不自动重发。
